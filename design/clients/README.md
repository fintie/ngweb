# Landing page company logos

Replaced the landing page's Selected projects section on 2026-11-02 at the user's request. The Projects page remains available. The user confirmed that this is their portfolio and requested the heading “Companies we’ve worked with” without mentioning the source agency on the public site.

Expanded to 13 brands after a second portfolio review and the user's requested additions: Coca-Cola, Alipay, ICBC, LOTTE × PHANTACi, Zambrero, Starlight Children’s Foundation, 85°C, CHEFIN, Luma Research, MGI Entertainment, Sushi Densha, Yasaka Ramen and Mackas Beef. Selection reflects recognisability and project attribution, not a measured ranking. The section makes no claim that these engagements involved AI, current retainers, endorsements or commercial outcomes.

Sources and original image URLs are recorded in `assets.json`, and the reviewed website inventory is saved in `portfolio-inventory.json`. Original logo PNGs are preserved in `references/`. Run `node design/clients/prepare-assets.cjs` from the repository root to proportionally resize and losslessly encode the artwork and update `site/src/data/clients.js`. CSS presents the existing artwork in monochrome. No logos were redrawn or generated.

The user explicitly requested animation after the carousel was implemented. Logos scroll continuously at 36 CSS pixels per second, with a duplicate runway for a seamless loop. Duplicate marks are hidden from assistive technology. At the user's later request, arrows, count and Play/Pause controls were removed. Hover pauses only on the actual logo images, including the loop copies; the heading, gaps and surrounding section do not trigger hover pause. Native touch/keyboard scrolling remains available, keyboard focus pauses movement and Space toggles its paused state. Manual interaction, leaving the viewport and a hidden browser tab also pause it. Reduced-motion preferences disable autoplay. Five logos fit desktop, three tablet and two phone screens. The strip has no internal vertical padding so the hit area stays compact.

The user subsequently requested researched estimates for private businesses and ordering by those estimates. `estimates.json` now supplies central AUD value proxies, ranges, scopes, confidence and sources for all 13 entries. The preparation script sorts these values descending. ICBC's A and H share classes are valued separately; private businesses use stated scenarios and Starlight uses reported charity net assets. No valuation figures are displayed on the public page. See `VALUATION-RESEARCH.md` for the current research and calculations; it supersedes the initial ordering notes.

Instagram's public metadata confirmed the Creative Mindx account, but post content was not available for reliable additional client attribution.
